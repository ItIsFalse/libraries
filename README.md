# Libraries:

Добро пожаловать в репозиторий! Здесь я собираю различные полезные библиотеки и скрипты на Python.

---

### 1. [psutil] Информация о железе и системе

**Файл:** `psutil_lib/psutil_lib.py`

**Что умеет:**

- Собирает данные о процессоре (ядра, частота, загрузка).
- Показывает состояние оперативной памяти (RAM) и файла подкачки.
- Анализирует занятое место на дисках и скорость ввода/вывода.
- Выводит сетевые интерфейсы (IP, MAC-адреса) и трафик.
- Показывает статус батареи и время до разряда.
- Выводит список всех запущенных процессов.

### 2. [rembg] Удаление фона с фото

**Файл:** `rembg_lib/rembg_lib.py`

**Что умеет:**

- Удаляет фон с изображений с помощью нейросетей.
- По умолчанию использует легкую и быструю модель `isnet-general-use` (отлично справляется с волосами и сложными
  краями).
- В коде оставлен закомментированный вариант для тяжелой, но максимально качественной модели `birefnet-general`.
- Безопасен для коммерческого использования.

**Статус:** *Код готов. Для запуска потребуется установить зависимости (см. `requirements.txt`). При первом запуске
скачается модель нейросети в зависимости от выбранной.*

### 3. [pyautogui] Скрытый скриншот

**Файл:** `pyoutogui_lib/pyoutogui_lib.py`

**Что умеет:**

- Делает снимок всего экрана (`take_full_screenshot`).
- Делает снимок конкретной области по заданным координатам (`take_region_screenshot`).
- Позволяет сохранять файлы с заданными именами.

### 4. [Pillow] Обработка изображений

**Файл:** `pillow/pillow_lib.py`

**Что умеет:**

- Переводит картинки в черно-белые (градации серого).
- Изменяет размер на установленный базовый стоит 300x150.
- Поворачивает изображение на установленный угол базовый стоит 90 градусов.

### 5. [Pillow] Водяной знак (Watermark)

**Файл:** `pillow/pillow_lib_watermark.py`

**Что умеет:**

- Накладывает текстовый водяной знак на изображение.
- Делает текст полупрозрачным.
- Размещает текст в 4 строки по диагонали (45 градусов) с повторением.

### 6. [getpass] Защита паролем (Скрытый ввод)

**Файл:** `getpass_lib/getpass_lib.py`

**Что умеет:**

- Запрашивает у пользователя пароль, скрывая символы при вводе (что бы не подглядывали).
- Проверяет введенный пароль со значением, заданным в коде, у нас это "SECRET_PASSWORD"
- При успехе выводит содержимое защищенного текстового файла.

**Важно:** Для корректной работы скрытого ввода (`getpass`) скрипт нужно запускать **через встроенный Терминал**, а не
через кнопку Run. Иначе PyCharm будет отображать вводимые символы.

### 7. [python-barcode] Генератор штрих-кодов

**Файл:** `barcode_lib/python-barcode.py`

**Что умеет:**

- Генерирует штрих-код формата EAN-13 по заданным 12 цифрам.
- Автоматически вычисляет 13-ю контрольную цифру для сканеров.
- Создает два формата на выбор:

**PNG** — обычная картинка (удобно для вставки в документы).

**SVG** — векторный формат (идеальное качество для печати в типографии).

---

### 8. [Faker] Генератор тестовых данных (ФИО и тд.)

**Файл:** `faker_lib/faker_lib.py`

**Что умеет:**

- Генерирует реалистичные фейковые данные для разных стран: Россия (`ru_RU`), США (`en_US`) и Узбекистан (`uz_UZ`),
  также можно ставить свои страны.
- Создает ФИО, телефоны, email (с доменом `@gmail.com`), компании и адреса.
- Для Узбекистана используются кастомные списки компаний (MChJ, AJ) тут есть слабость которую нужно решить и улиц на
  узбекском языке, а также генерируются
  правильные местные номера телефонов (+998).
- Идеально подходит для заполнения баз данных или тестирования.

### 9. [countryinfo] Информация о странах

**Файл:** `countryinfo_lib/countryinfo_lib.py`

**Что умеет:**

- Запрашивает у пользователя название страны (на английском).
- Выводит полную информацию: столицу, население, площадь, валюты, языки, соседей, часовые пояса и координаты.
- Показывает альтернативные названия, ISO-коды, домены и ссылку на Википедию.

### 10. [Таблицы] Вывод данных в консоль

**Файлы:** `tables/prettytable_lib.py` и `tables/tabulate_lib.py`

**Что умеет:**

- **PrettyTable** (`prettytable_lib.py`): строит таблицу построчно, удобно для динамических данных.
- **Tabulate** (`tabulate_lib.py`): мгновенно форматирует готовый список, поддерживает красивые стили (`fancy_grid`,
  `github` и др.).

---

### 11. [qrcode] Умный генератор QR-кодов

**Файл:** `qrcode_lib/qrcode_lib.py`

**Что умеет:**

- Интерактивное меню для выбора типа данных (текст, звонок, email, Wi-Fi, геолокация).
- Автоматически формирует правильные префиксы (`tel:`, `mailto:`, `WIFI:`, `geo:`), чтобы смартфоны понимали, что делать
  при сканировании.
- **Вставка логотипа:** Опционально добавляет картинку (`test_photo.png`) в центр QR-кода.

---

### 12. [stegano] Стеганография (скрытые сообщения)

**Файл:** `stegano_lib/stegano_lib.py`

**Что умеет:**

- Прячет текстовое сообщение внутри пикселей изображения (метод LSB).
- Извлекает скрытый текст из картинки обратно.
- **Важно:** Для сохранения скрытых данных картинку нужно сохранять строго в формате **PNG** (формат JPG сжимает пиксели
  и может уничтожить секретное сообщение).
