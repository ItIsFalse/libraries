### 1. [psutil] Информация о железе и системе

**Файл:** `psutil_lib/psutil_lib.py`

**Что умеет:**

- Собирает данные о процессоре (ядра, частота, загрузка).
- Показывает состояние оперативной памяти (RAM) и файла подкачки.
- Анализирует занятое место на дисках и скорость ввода/вывода.
- Выводит сетевые интерфейсы (IP, MAC-адреса) и трафик.
- Показывает статус батареи и время до разряда.
- Выводит список всех запущенных процессов.

### 2. [rembg] Удаление фона с фото

**Файл:** `rembg_lib/rembg_lib.py`

**Что умеет:**

- Удаляет фон с изображений с помощью нейросетей.
- По умолчанию использует легкую и быструю модель `isnet-general-use` (отлично справляется с волосами и сложными
  краями).
- В коде оставлен закомментированный вариант для тяжелой, но максимально качественной модели `birefnet-general`.
- Безопасен для коммерческого использования.

**Статус:** *Код готов. Для запуска потребуется установить зависимости (см. `requirements.txt`). При первом запуске
скачается модель нейросети в зависимости от выбранной.*

### 6. [getpass] Защита паролем (Скрытый ввод)

**Файл:** `getpass_lib/getpass_lib.py`

**Что умеет:**

- Запрашивает у пользователя пароль, скрывая символы при вводе (что бы не подглядывали).
- Проверяет введенный пароль со значением, заданным в коде, у нас это "SECRET_PASSWORD"
- При успехе выводит содержимое защищенного текстового файла.

**Важно:** Для корректной работы скрытого ввода (`getpass`) скрипт нужно запускать **через встроенный Терминал**, а не
через кнопку Run. Иначе PyCharm будет отображать вводимые символы.

### 7. [python-barcode] Генератор штрих-кодов

**Файл:** `barcode_lib/python-barcode.py`

**Что умеет:**

- Генерирует штрих-код формата EAN-13 по заданным 12 цифрам.
- Автоматически вычисляет 13-ю контрольную цифру для сканеров.
- Создает два формата на выбор:

**PNG** — обычная картинка (удобно для вставки в документы).

**SVG** — векторный формат (идеальное качество для печати в типографии).

### 14. [argostranslate] Офлайн-переводчик

**Файл:** `translator_lib/deep-translator_lib.py`

**Что умеет:**

- Переводит текст полностью (без интернета) с использованием нейросетей.
- Сейчас настроен на русский ↔ английский (остальные языки легко добавить в коде).
- Работает без лимитов, блокировок и ошибок 429 от Google.

**Важно про скачивание:**
При первом запуске (если раскомментировать блок загрузки в коде) библиотека **скачивает языковые модели** (около 150–200
МБ на пару языков) в папку пользователя. После этого перевод работает локально и мгновенно.

**Для кого этот инструмент:**
Идеально для любителей и новичков, которые хотят понять, как работают нейросети в переводе, и не хотят зависеть от
интернета или платных API.

### 16. [Custom] Локальный фильтр нецензурной лексики

**Файл:** `ban_words/test_ban.py` (и база `ban_words_2024.txt`)

**Что умеет:**

- Проверяет текст на наличие запрещенных (нецензурных) слов.
- Использует **собственную локальную базу** `ban_words_2024.txt` (содержит слова на русском и английском, поддерживает
  запись через запятую или с новой строки).
- Работает полностью офлайн, без интернета и сторонних API.

**Почему без библиотеки:**
В коде есть закомментированный пример с популярной библиотекой `glin-profanity`. Короче говоря он тянет много
зависимостей так что проще просто свою бд создать и оттуда проверять слова. Если найду (если буду искать З), то добавлю
информацию.

### 17. [GPU] Мониторинг видеокарты

**Файлы:** `gpu_2lib/GPUtil_lib.py` и `gpu_2lib/PyLibreHardwareMonitor_lib.py`

В папке реализованы два подхода к мониторингу видеокарт с использованием разных библиотек:

**1. GPUtil (`GPUtil_lib.py`)**

- **Для чего:** Создана специально для дискретных видеокарт **NVIDIA**.
- **Что показывает:** Загрузку, объем видеопамяти (свободно/занято/всего) и температуру.
- Для работы требуется установленный драйвер NVIDIA.

**2. PyLibreHardwareMonitor (`PyLibreHardwareMonitor_lib.py`)**

- **Для чего:** Универсальная библиотека для чтения датчиков (подходит для встроенной графики **Intel/AMD** и
  процессоров).
- **Что показывает:** Температуру, нагрузку и другие данные с датчиков.
- Для работы библиотеки необходимо скачать утилиту **LibreHardwareMonitor
  ** https://github.com/LibreHardwaRemonitor/LibreHardwareMonitor и запустить её в фоне.
